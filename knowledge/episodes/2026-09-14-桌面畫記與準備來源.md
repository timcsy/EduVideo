# 桌面畫記與準備來源

使用者要求剪輯人像預設鏡像，視窗／螢幕錄製也能畫記，離開工作室後仍能使用畫記與講者筆記，並可預先準備來源快速切換。

## 實作決策

- 桌面方向沿用使用者選定的 Electron。透明畫記層、可拖曳工具列、筆記視窗與快捷鍵由 Electron 管理；Web 保留工作室內的標記與來源切換。
- 使用固定的 1280×720 錄製畫布，在不同來源間切換繪製內容，保持同一個 MediaRecorder；講者媒體仍獨立錄製。
- 準備清單保留本次工作階段的分享串流。切換不停止其他串流；移除來源才停止分享，來源結束時退回簡報。畫記文件按來源分開。
- 新人像預設鏡像，明確保存的鏡像設定優先，預覽與輸出共用 DEFAULT_LAYOUT。
- 單視窗桌面畫記採手動對齊內容範圍；螢幕來源按 display ID 自動對齊。工具開啟時註冊快捷鍵，關閉、進入剪輯或關閉工作室時釋放。

## 測試發現

只有視訊、沒有聲音的分享來源，搭配尚未輸出音訊的 AudioContext destination，可能讓 MediaRecorder 產生零位元組的畫面檔。連續的零值 ConstantSource 維持音訊時鐘，避免無聲來源阻塞錄製。

單元測試驗證鏡像預設及顯式設定、來源切換不停止串流、移除與回退、獨立標記資料、等比例座標。隔離 Electron 流程測試驗證真實工具視窗 IPC、筆記同步、外部畫記進入錄製畫布、來源切換後保存影片的實際影格，以及停止後鏡像剪輯與快捷鍵釋放。TEST_REAL_CAPTURE=1 路徑使用專用測試視窗做真正的桌面擷取，攝影機仍是合成測試來源。

## 明確界線

### 0.7.1 可用性修正

使用者回報工具隱藏後無法快速喚回，以及準備來源壓縮主畫面。工具生命週期因此拆成啟用與顯示兩個狀態：隱藏保留 H 喚回快捷鍵，進入剪輯或退出才取消註冊。工具改為有文字提示的精簡圖示，來源清單移至左側。來源選擇器以 minmax(0,1fr)、min-width:0 和固定縮圖比例消除圖片原始尺寸引起的欄寬失衡。

全螢幕來源預設以 CSS 隱藏工作室人像預覽，獨立相機錄製不受影響；可選擇顯示人像及允許系統擷取工作室與工具。工具排除仍受 macOS 限制。隔離 Electron 測試涵蓋隱藏後註冊仍存在與重新顯示、來源選擇器等寬無溢出、全螢幕預覽開關、圖示工具列尺寸，以及整條錄製／保存流程。

目前標記燒錄於畫面素材中，不是後製可移除的獨立圖層。來源分享授權不保存到磁碟，重開程式需重新準備。macOS ScreenCaptureKit 可能忽略 setContentProtection；不宣稱講者筆記在整個螢幕錄製下永不入鏡。

### 0.8.0：互斥工作區與分離的預覽／擷取設定

使用者進一步指出「返回工作室」與「隱藏主視窗」難以分辨，希望工作室與小工具互斥顯示、錄製鍵恆常存在，並明確區分人像預覽及是否擷取 EduVideo 視窗。

- 工具只留一個房子按鈕返回工作室，H 在兩個介面間切換。返回時同時收起浮動筆記、人像與畫記層，但保留來源串流及快捷鍵。停止保存後回剪輯。
- 第一排固定放畫記工具、復原、垃圾桶、筆記與人像開關；第二排放開始／停止、暫停／繼續及來源／翻頁。空白待機時也可開始，未初始化相機時先取得權限，工具標頭顯示倒數及錄製狀態。
- 人像浮窗透過本機 WebRTC 共用既有的視訊 track，沒有額外麥克風，也不重新開相機；鏡像只作用於預覽。隱藏浮窗時停止預覽連線，不停止原始人像錄製。重新載入主頁後可重新交換連線訊號。
- 「包含 EduVideo 相關畫面」移到右側錄製設定，只在整個螢幕來源生效；不再使用 CSS 隱藏人像冒充系統排除。使用者接受系統無法排除的限制，UI 明確要求試錄確認，並提醒私人筆記使用未錄製螢幕。
- 簡報側欄支援拖曳／按鈕排序、在選取頁後插入 PDF／圖片／空白頁、複製、刪除、復原與重做。歷史快照包含標記，複製頁的標記獨立，資料進入原有 .eduv 儲存鏈；錄製中鎖住結構修改，仍可翻頁。

驗證包含純邏輯單元測試，以及隔離 Electron 中的互斥視窗、人像連線與重新連線、擷取排除請求、不開工作室直接錄製、倒數、暫停／停止、簡報排序與復原、專案封裝及重新載入。真實視窗來源使用專用測試視窗，相機保持合成來源；系統排除請求成功不等於系統一定遵守。
