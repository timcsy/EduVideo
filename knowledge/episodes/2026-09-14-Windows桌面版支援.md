# Windows 桌面版支援

> 日期：2026-09-14

使用者問「要如何在 macOS 以外的平台也可以用」，選擇先做 Windows。

## 分析時衡量過的阻礙

前端 src/ 是純瀏覽器模組，沒有 window.studioNative 時會退回瀏覽器路徑，因此問題集中在 Electron 主程序與打包：

- **原生語音：**native/speech/whisper-cli 是連結 Metal 的 arm64 Mach-O，transcribe.mjs 寫死檔名。選項是 CI 為每個平台編譯，或第一版改用既有的瀏覽器 WebAssembly 辨識；選擇前者。
- **打包與 CI：**electron-builder 只有 mac 設定，release.yml 只跑 macos-14；ffmpeg-static 在安裝時只下載當前平台的執行檔，所以每個平台必須在自己的 runner 上 npm ci。
- **.eduv 專案：**macOS 靠 LSTypeIsPackage 把資料夾顯示成單一檔案；Windows 上是一般資料夾，不能設定檔案關聯，open-file 事件也只存在於 macOS。開檔對話框同時要求 openFile 與 openDirectory 時，Windows／Linux 只會變成資料夾選擇器，舊的 .zip／.eduvideo 就選不到。
- **桌面小工具：**setContentProtection、透明畫記層滑鼠穿透、全域快捷鍵在 Windows 都有對應實作；Linux（尤其 Wayland）多項失效，因此暫不處理，見 [](../draft/2026-09-14-Linux桌面版.md)。
- **Tauri：**src-tauri 只是空殼，沒有任何命令，排除作為跨平台路徑，見 [](../history/004-從Tauri跨平台設定到Electron跨平台桌面主線.md)。

## 實作中發現的兩個隱性錯誤

兩者在 macOS 上都測不出來：

1. **Windows 命令列字碼頁。**讀 whisper.cpp v1.8.3 原始碼發現，cli.cpp 在 Windows 上以系統字碼頁（繁中 Windows 為 Big5）接收 argv，但 whisper.cpp 把模型路徑當 UTF-8 轉寬字元開啟，音訊則用窄字元 fopen。使用者名稱含中文時，模型與暫存路徑都會壞；繁中提示詞也會變成亂碼送進 tokenizer。解法是讓 whisper-cli 讀 UTF-8 回應檔（@args.txt）、工作目錄設為暫存資料夾、音訊與輸出改用相對路徑，模型保留 UTF-8 絕對路徑。三個平台共用同一套寫法，所以 macOS 的實測也覆蓋了 Windows 的程式路徑。
2. **asar 路徑分隔符號。**打包版把 ffmpeg 從 app.asar 換到 app.asar.unpacked 時，只替換了 `app.asar/`；Windows 路徑是反斜線，替換不會發生，MP4 匯出與辨識前的音訊轉換都會找不到 ffmpeg。

## 驗證

- 單元測試 97 個通過，包含執行檔名稱、兩種分隔符號的 asar 路徑、回應檔內容、各平台對話框能力、命令列開檔與快捷鍵提示。
- macOS 本機：模型與暫存目錄放在中文資料夾下，以真正的 whisper-cli 辨識通過；隔離 Electron 中透過 IPC 下載模型並辨識通過；macOS 打包只含 whisper-cli。
- GitHub Actions 手動執行 [34823533873](https://github.com/timcsy/EduVideo/actions/runs/34823533873)：Windows runner 以靜態 MSVC runtime、關閉 OpenMP、固定 AVX2 編譯 whisper-cli.exe，在中文路徑下辨識出 “ask not what your country can do for you”，並確認安裝檔內含 whisper-cli.exe 與 ffmpeg.exe、不含 macOS 執行檔。
- scripts/test-recording-workspace.mjs 在「include switch releases capture protection」一步失敗；以原始程式重建 dist 後同樣失敗，屬於既有問題，不是這次引入。
- 使用者在 Windows 上實際安裝後回報：「windows可以用耶！」。沒有逐項回報測了哪些功能，桌面小工具在 Windows 上的擷取排除行為仍未個別確認。

## 結果

0.9.0 起 Electron 同時發布 macOS Apple Silicon 與 Windows x64（預覽）。教訓提煉到 [](../experience.md) 的「平台轉接層要在目標平台的真實邊界上驗證」。
