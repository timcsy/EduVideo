# 001：從混用段落時鐘轉向共用字詞時鐘

> 日期：2026-09-12

## 轉變

- **舊：**字幕切分在有精確字詞比對時使用 token；必要時卻退回按段落比例估算時間。Whisper JSON 先被當成一般 UTF-8 文字解析，再逐一比對 token；時間軸的空白鍵又被通用的輸入焦點規則擋住。
- **新：**先把原始 Whisper 位元組重新組合成有效的 UTF-8 字詞，再進行比對；可讀字幕共用一個來源時鐘並使用局部插值；保留並合併零長度字詞與句尾語助詞；時間軸互動會恢復播放頭焦點，並明確處理空白鍵重播。

## 為什麼改變

專案紀錄與使用者觀察到的失敗顯示，字幕文字、字幕時間與播放焦點並不是互相獨立的問題。被切開的 UTF-8 token 片段無法可靠地精確比對，導致備援時間估算與畫面重疊；句尾語助詞也可能變成只有一個字元的字幕。另一方面，時間軸互動後空白鍵可能落在字幕搜尋欄位，因而看起來像重播壞掉。修正同時改變了表示方式與焦點政策，並加入針對性測試。

因果解釋有一部分是根據實作與測試證據推測；commit 主旨與後續測試結果證明了變更，但沒有記錄每個最初的設計討論。
