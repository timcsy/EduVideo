# Linux 桌面版

> 由 Windows 桌面版支援的分析於 2026-09-14 提出；使用者選擇先放草稿，不列入路線圖。

Electron 主程序已經依平台處理執行檔名稱、asar 路徑、開檔對話框與命令列開檔（electron/platform.mjs），所以 Linux 缺的主要不是程式碼，而是平台能力的界線：

- setContentProtection 在 Linux 沒有作用，整個螢幕錄製時講者筆記與小工具一定會入鏡，需要 UI 明確提醒。
- 透明畫記層需要合成器；setIgnoreMouseEvents 的 forward 選項不支援。
- Wayland 上 globalShortcut 預設無效，需要 GlobalShortcutsPortal；desktopCapturer 走 PipeWire 選擇器，自訂來源選擇器與 display_id 可能拿不到值。
- whisper-cli 需要在 Linux runner 上編譯，打包目標可從 AppImage 開始。
