# 願景

## 問題陳述

教學者需要一邊解說簡報，一邊呈現自己的影像，之後還能在不破壞投影片、講者影片、聲音、標記與字幕關係的情況下修整錄製內容。扁平化的最終影片很難修正；工作中的專案必須持續可理解且可編輯。

## 核心想法

EduVideo 是 local-first 的教學影片工作室：分開錄製簡報與講者媒體，在預覽時把它們一起呈現，再透過可復原的專案資料夾編輯同步後的結果。

## 目前狀態

目前的 Studio 0.9.0 實作包含瀏覽器式錄製工作區、投影片標記、講者合成、非破壞性時間軸剪輯、素材管理、.eduv 資料夾專案、可編輯字幕與辨識路徑，以及可選用原生語音模型的 Electron 桌面執行環境；桌面版發布 macOS Apple Silicon 與 Windows x64（預覽）。桌面工具支援與工作室互斥顯示、固定錄製控制、獨立人像預覽、準備來源切換與簡報頁面管理；重播與字幕時間修正已有自動化測試涵蓋。

目前歷史沒有確立去背邊緣與轉錄準確度的完成品質門檻；這些仍保留為待定草稿。

## 架構

UI 與領域邏輯以瀏覽器導向的模組組成。分離的媒體軌道與可編輯專案狀態會在預覽或輸出時合成。Electron 是唯一的桌面產品，透過 IPC 處理本機專案檔案、編碼與語音辨識，平台差異集中在主程序的轉接層；瀏覽器版保留為不安裝的路徑，語音走獨立的 WebAssembly／API。支援的執行環境矩陣見 [](history/004-從Tauri跨平台設定到Electron跨平台桌面主線.md)。.eduv 內的 media 與 revisions 資料夾保存專案邊界，下載的語音模型則留在專案外部。
