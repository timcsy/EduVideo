# EduVideo Studio

## Studio 2 · 0.6.2

本版桌面安裝檔適用 Apple Silicon、macOS 15 以上。80 項單元測試，另有打包版錄製／匯出、原生專案保存、持續播放剪輯、桌面模型下載與瀏覽器 WebAssembly 字幕辨識測試。

### 0.6.2：重播焦點與字幕時間修復

點擊／拖曳時間尺後，焦點會回到播放頭，避免空白鍵仍落在先前的字幕搜尋欄。時間軸縮放滑桿也支援空白鍵，長按不會反覆切換播放／暫停。`scripts/test-replay.mjs` 驗證自然播放結束後重播、移回開頭重播、縮放滑桿焦點，以及輸入文字時不誤觸播放。

修正 whisper.cpp JSON 中單一中文字的 UTF-8 位元組分散於多個 token 的解碼問題。先合併位元組再解碼，保留完整文字和時間區間，零時長 token 也保留。所有子句使用同一份原始時間座標；部分 token 缺漏時只在鄰近時間錨點間插值，不再把部分字幕的整段比例估算與其他字幕的辨識時間混用。句尾「呢」等語氣詞不因停頓獨立成句，跨辨識段落的尾詞也會合併。

辨識後在素材的 `captionSource` 保留原始逐字稿、token 時間、模型名稱與語言，不包含 API Key。手動修改文字保留原始時間證據。已有錯誤字幕可按「從音訊重新辨識（修復時間）」重建，會取代字幕、可復原；僅按重新斷句無法恢復舊版本已丟失的時間。辨識時間仍有模型誤差；API／瀏覽器若只提供段落時間，細分時間仍屬估算，需校對。

### 0.6.1：無標點口語斷句與側欄整理

加入中文句尾語氣詞搭配後續語句、主語重新開始等線索，改善無標點教學逐字稿整段顯示的問題，同時保留條件句及「希望／知道」等引導的從句。以使用者回報的「OK那那到底文字資料在幹嘛呢……」原文驗證會切為六句，原文字詞不變。現有字幕需按「重新自然斷句（全片）」套用，可復原；未附逐字時間的旧字幕仍採分句時間估算。

字幕辨識、匯入／匯出、外觀及重新斷句功能排在上方，字幕搜尋和清單位於所有功能下方。素材卡片只保留縮圖預覽、加入時間軸及更多操作；收藏、重新命名、定位、下載、移除集中在「⋯」選單，支援鍵盤方向鍵與 Escape。另將素材区的專案按鈕收進「專案操作」。首次載入素材等待影格完成解碼再顯示，避免暫停在零秒時預覽黑畫面。

### 0.6 新增：自然斷句、全片字幕工作區與素材預覽

字幕斷句移除字數／秒數硬切限制，使用語言句界、標點、轉折連接詞和可靠逐字時間中的停頓。可選「自然子句」或「完整句子」，不會任意切斷無標點的長句、英文單字或小數。這是本機語言規則與時間資訊的判斷，並非另跑大型語言模型改寫；沒有逐字時間時，分句的時間仍需估算。桌面 Whisper 現在保留 token 時間，Whisper-1 API 同時要求逐字與段落時間。已有字幕可按「重新自然斷句（全片）」，可復原。

字幕清單預設顯示整支影片，支援全文搜尋、選取片段篩選、每頁 40 句、影片時間跳轉、定位目前字幕、播放高亮與自動跟隨。編輯中的文字不會因播放跟隨而被切換；選取句子才展開文字、起終時間及分割／合併／刪除。可跨片段編輯，Cmd/Ctrl+Enter 前往下一句，Escape 收合。0.6.1 起，匯入、辨識與樣式設定位於清單上方。

素材卡片可點縮圖播放原始畫面、人像或雙畫面，支援進度拖曳、預設鏡向人像、直接加入時間軸，以及列出全部使用位置。收藏隨專案保存；素材可依收藏／使用狀態篩選，並依名稱／長度／大小／加入順序排序。預覽關閉後釋放影片與 Blob URL。`scripts/test-v6-flow.mjs` 使用隔離的 300 句字幕專案驗證搜尋、跨片段修改、分頁、時間跳轉、收藏保存及素材播放。

桌面版以 `studio.html` 為入口。先匯入 PDF／圖片或選取視窗，開啟相機與麥克風，三秒倒數後分開錄製畫面及人像。內部人像預覽採鏡像；錄製可以暫停及繼續，停止後進入剪輯工作區。

時間軸支援同步分割、裁切、刪除、重排、復原／重做。成品人像的位置、大小、鏡像、顯示及去背設定同時套用至預覽與匯出。桌面版提供 MP4（H.264/AAC）及 WebM，去背模型、PDF 渲染器與 MP4 編碼器隨程式提供。網頁版可匯出 WebM。

素材與剪輯自動暫存於本機資料庫；按「儲存專案」或 ⌘S 才會寫入磁碟上的 `.eduv` 專案。桌面版使用未壓縮資料夾封裝（Finder 中可視為一份文件），其中 `media/` 保留以 SHA-256 去重的原始影片，`revisions/` 保留歷次儲存的設定，`project.json` 指向目前版本。儲存時先寫入新版本，再切換目前版本，且不刪除原始素材。可用「另存專案」複製整份專案；搬機時複製整個 `.eduv`，不要只複製內部 JSON。網頁版下載同副檔名的可攜封裝檔；仍可開啟舊 `.eduvideo`／ZIP。錄製中每五秒寫入備援，可能遺失最後尚未保存的數秒；本機暫存不應當作唯一備份。

### 標記簡報

匯入 PDF 或圖片後，可選畫筆、螢光筆、箭頭、直線、矩形、橢圓、文字、橡皮擦與雷射筆，調整顏色與粗細。「選取／移動」可拖動標記；支援刪除選取、清除、逐頁復原／重做。文字先在工具列輸入，再點簡報放置。雷射筆為短暫指示，錄製當下會出現在畫面。標記目前針對匯入的簡報，不覆蓋外部視窗錄製；錄下的標記已在畫面素材內，後製無法從原始影片移除。

### 剪輯與分段人像

側欄分成「剪輯／人像」。點時間軸片段後，常用分割、刪除並接合、複製、排序、裁切到播放頭都在剪輯頁最上方。拖片段本體排序，拉兩端裁切或延伸回原始素材。時間軸提供首幀縮圖、實際音訊波形（可解碼時）、縮放與逐格移動；每段支援 0.25–4 倍速度、0–100% 音量、黑場／音訊淡入淡出和單行下方標題。縮圖是素材首幀的視覺提示，不是連續逐幀縮圖。

人像的顯示、位置、尺寸、矩形／圓角／圓框、鏡像、填滿裁切、內部放大、背景、框線與陰影皆為**每片段設定**。例如先在 10 秒分割，再選後段取消「顯示人像」，10 秒後就不會出現人像。再分割下一段可恢復顯示或改變位置。拖曳預覽人像會自動打開人像設定。背景可選純色、漸層、原背景模糊或自訂圖片（會保存在專案內）；選擇新背景會啟用去背。

去背改用一般人像模型，提供閾值、邊緣柔化與時間穩定度。提高穩定度可降低閃爍，但可能產生殘影；髮絲、手部與快速移動仍受光線和模型能力影響，不保證攝影棚等級。預覽與匯出共用這些設定，不修改原始影片。

快捷鍵：空白鍵播放／暫停；S 或 ⌘B 分割；I／O 設定起終點；Delete 刪除並接合；⌘C／X／V 複製／剪下／貼上；⌘D 複製片段；⌘Z／⇧⌘Z 復原／重做；方向鍵逐格，Shift＋方向鍵一秒；⌘S 儲存專案。

### 0.4 新增：素材管理、播放頭與字幕

素材庫提供縮圖、名稱搜尋、使用中／未使用篩選、使用次數與容量，展開素材卡可改名、定位使用處、重新加入時間軸、下載原始檔或移除。移除只影響目前專案，可在本次工作階段復原；不刪除已存磁碟專案的舊版本。人像外框與縮放圓點只在選取人像或開啟人像側欄時顯示，點空白、切回其他側欄或 Escape 時隱藏；播放中仍可選取並直接拖曳調整。

人像側欄內建三張離線背景：暖色書房、花園露臺、簡約工作室，由 imagegen 原創生成。圖片與完整提示詞見 `src/assets/backgrounds/README.md`。專案記錄穩定的 preset ID；不記錄本機絕對路徑。

時間軸改為貫穿畫面／音訊／字幕的直式播放頭，可拖曳播放頭或點時間尺定位。磁吸按鈕可開關，拖曳時 Alt 暫時停用。目標包含剪接點、字幕邊界，以及以 20ms 音訊能量視窗偵測的聲音／停頓邊界；裁切把手也能吸附原始素材起終點、播放頭、字幕與聲音邊界。這是時間點輔助，不是內容語意判斷、逐字對齊或獨立多軌同步工具。

「字幕」側欄支援中文／英文／日文／自動語言、逐句文字與影片起終時間編輯、手動新增／刪除、SRT 匯入／匯出，以及樣式、字級、位置、色彩、透明度、外框與字重。離線模型與 API 模式詳見下一節。文字與時間碼皆應校正；任何模型都可能錯字、漏字或在背景聲音上產生誤辨識。

字幕保存在片段的原始素材時間軸，裁切、分割、重排與變速會自動映射到成品時間。SRT 匯入使用整支影片的成品時間，會取代現有字幕（有確認）；匯出亦使用剪輯後的成品時間。辨識此片段會讀取該段所屬的原始麥克風素材，僅把結果套用至選取片段；辨識全部會依素材去重處理。取消辨識保留原有字幕。預覽與影片匯出共用字幕繪製，SRT 亦可獨立下載。瀏覽器／Codex 內建瀏覽器的預覽可手動編輯和匯入字幕，但自動辨識需要桌面版的原生引擎。

可把播放頭移到字幕中間，於文字欄指定游標位置，再按「在播放頭分割」，同時切開文字與時間範圍。0.6 起採用上述自然斷句，不再限制每句字數與秒數。長字幕仍會自動換行並縮小，避免截掉尾端文字。

### 0.5 新增：不中斷播放剪輯、按需模型與字幕樣式

開始播放後，調整片段速度／音量、人像位置／大小／去背參數、字幕內容與外觀，或拖動播放頭，都會保留播放狀態並從目前結果繼續播放。分割、裁切、刪除、重排、復原／重做也會在套用後續播；切換錄製模式、開始匯出、開啟／建立專案等工作流程邊界仍會停止播放。

桌面安裝包只內含 whisper.cpp 原生引擎，不預裝任何模型。字幕側欄可選 tiny（75 MB）、base（142 MB）、small（466 MB）、large-v3-turbo q5（547 MB，桌面推薦）、large-v3-turbo（約 1.5 GB）或 large-v3（約 2.9 GB），需要時才從官方模型庫下載；下載有進度、取消、SHA-1 校驗與移除功能。模型放在 App 的使用者資料目錄，不寫入 `.eduv`。

網頁版可把 tiny／base／small 下載或匯入 IndexedDB，並用 whisper.cpp WebAssembly 在本機辨識；預設 tiny，因為官方亦指出瀏覽器執行 medium／large 的記憶體與速度不理想。主機必須送出 COOP／COEP 跨來源隔離標頭，本專案的 `npm start` 已設定。網頁與桌面皆可改用 OpenAI 或 OpenAI 相容的 HTTPS transcription API；API Key 只留在當次頁面記憶體，不寫入專案、IndexedDB 或 localStorage。GPT-4o Transcribe 的純 JSON 回應沒有段落時間時，EduVideo 會按素材時長估算字幕區間；要原生段落時間可選 GPT-4o Transcribe Diarize 或 Whisper-1。

字幕樣式新增深色底板、文字外框、柔和陰影、純文字與品牌色側條，並能調整文字／底板／外框／強調色、底板透明度、外框粗細、字重、字級及上／中／下位置。預覽與輸出仍使用同一套 Canvas 繪製。

目前仍是同步剪輯工具，不是完整通用 NLE：尚無獨立多軌疊片、關鍵影格動畫、跨片段交叉溶解或任意素材匯入。人像樣式在片段邊界切換，沒有內插動畫。輸出固定 720p，桌面捕捉目前不含系統內部聲音。

驗證：`npm test` 執行單元測試；`node scripts/test-studio.mjs` 在隔離的 Electron 測試視窗執行錄製、暫停、裁切、去背、MP4、拖曳及重開專案驗證，需要測試程序的除錯埠 9226 和開發機上的 ffprobe。測試使用模擬相機與音訊。

`scripts/test-native-package.mjs` 另外驗證 `.eduv` 原生 IPC 儲存／開啟（需隔離測試程序的 main inspector 9230；僅替換選檔對話框的回傳路徑，不替換儲存程式）。請勿對平常使用中的 App 執行這些測試。

字幕驗證另有 `scripts/test-speech.mjs`、`scripts/test-v4-flow.mjs`、`scripts/test-v5-flow.mjs`、`scripts/test-v5-speech.mjs` 與 `scripts/test-browser-speech.mjs`。它們分別涵蓋原生辨識、字幕燒錄／保存、播放中調整、真正下載／校驗／指定／移除桌面模型，以及在無 Electron 能力的 Chrome 中從 IndexedDB 執行真正的 whisper.cpp WebAssembly 辨識。JFK 音訊只作已知英語測試素材；中文與實際課程仍需人工校對。

以下內容保留作為舊版架構參考；Studio 2 的功能以上述說明為準。

EduVideo Studio 是一個以瀏覽器為核心的教學影片錄製與剪輯工作區，目標是讓講者同時看見簡報、人像預覽、提詞器與可編輯時間軸。使用現代瀏覽器即可在 Windows、macOS、Linux 執行，不綁定雲端服務。

## 已完成的 MVP

- 同時請求螢幕與相機／麥克風權限，分開錄製螢幕與人像 WebM 素材
- 錄製時自動開啟「純簡報輸出」視窗，避免把操作介面與人像預覽錄進螢幕素材
- 工作區內的人像預覽採水平鏡像，原始人像素材維持正常方向供後製使用
- 簡報頁面切換、圖片匯入，以及 PDF 頁面轉成投影片
- 投影片上的畫筆、螢光筆、箭頭、文字與橡皮擦標記
- 可編輯提詞稿與自動捲動
- 三軌時間軸：簡報、人像、麥克風
- 片段選取、播放頭定位、分割、裁切開始、裁切結束與刪除
- 時間軸播放／暫停與 Space 快捷鍵
- 時間軸片段拖曳移動與多軌對齊
- 專案資料自動保存到瀏覽器、JSON 專案匯出，以及獨立螢幕／人像素材匯出
- 錄製結束後可直接在工作區預覽兩個獨立素材
- 可將螢幕畫面與人像疊合成單一 WebM 成品預覽，並混合螢幕／系統音訊與相機麥克風音訊
- 可在錄製後使用 MediaPipe Selfie Segmentation 逐幀去背，再合成人像素材
- 復原／重做按鈕與 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z、Ctrl/⌘+Y 快捷鍵

## 開發

```bash
npm test
npm start
```

開啟 <http://127.0.0.1:4173/>。內建開發伺服器會設定跨來源隔離標頭，讓瀏覽器能使用 FFmpeg WASM 輸出 MP4；錄製功能需要在 localhost 或 HTTPS 環境中授予瀏覽器螢幕與相機權限。若部署到其他靜態主機，也需要設定 `Cross-Origin-Opener-Policy: same-origin` 與 `Cross-Origin-Embedder-Policy`，否則工具會提供 WebM 備援下載。

## 桌面版

目前建議的桌面殼是 Electron；它能在應用程式內完成螢幕、相機與麥克風錄製：

```bash
npm install
npm run electron:dev
npm run electron:build
```

錄製時請在來源選擇器選最前面的「EduVideo 簡報輸出」。主工作區仍可顯示鏡像人像、逐字稿與大綱，但螢幕素材只包含簡報和標記；停止後會直接顯示螢幕與人像兩個獨立素材並展開剪輯區。

專案仍保留 Tauri 2 設定作為較輕量的跨平台殼，但 macOS Tauri WebView 不提供 `getDisplayMedia`，因此它只適合簡報與剪輯介面，不是目前建議的完整錄製版本：

```bash
npm run desktop:dev
npm run desktop:build
```

macOS 14.2 以上若要擷取系統音訊，還需要使用者在「系統設定 → 隱私權與安全性 → 螢幕與系統音訊錄製」授權 EduVideo。目前 Electron 路徑穩定提供簡報畫面、人像與麥克風分開錄製；系統音訊回錄會依作業系統與權限狀態決定是否可用。Electron 版本的錄製能力比 Tauri WebView 完整，但應用程式體積會較大。

## 架構

- `src/state.js`：可測試的專案狀態與剪輯操作
- `src/capture.js`：MediaRecorder 錄製層
- `src/slides.js`：圖片／PDF 投影片匯入層
- `src/project.js`：專案序列化與檔案匯出
- `src/media.js`：獨立錄製素材預覽 URL
- `src/composition.js`：螢幕／人像畫布合成
- `src/background.js`：錄製後 MediaPipe 人像去背
- `src/mp4.js`：FFmpeg WebAssembly MP4 編碼
- `src/app.js`：瀏覽器介面與互動繫結

目前錄製與合成素材以 WebM 為主，MP4 編碼透過 FFmpeg WebAssembly 轉換。MediaPipe 與 FFmpeg 模型／核心目前從 CDN 載入，若要完全離線，需要將資產納入發佈包；不具備跨來源隔離的環境會自動下載可播放的 WebM 成品，並提示使用者原因。
